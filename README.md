# Quant Developer Roadmap

A structured, self-paced plan to become a **quantitative developer** — the
engineering role that sits between quantitative research and production
trading systems. This repository holds my roadmap, job-market research, and
detailed study plans.

## How to use this repo

- Work the phases in order; each has concrete, checkable milestones.
- Treat the job-market research as a moving target — revisit it quarterly.
- Keep a learning log (commit progress notes) so you can see momentum.
